## 🌟 Overview

The HAMOTECH Email Signature Generator is a fully functional, single-page web application that allows users to create professional email signatures with a futuristic cyberpunk aesthetic. Built with pure HTML, CSS, and JavaScript, it requires no backend or dependencies.

### Why Use This Generator?

- ✅ **No Sign-up Required** - Use it instantly in your browser
- ✅ **100% Free & Open Source** - Modify and use as you wish
- ✅ **Privacy First** - All processing happens locally in your browser
- ✅ **Email Client Compatible** - Works with Gmail, Outlook, Apple Mail, and more
- ✅ **Responsive Design** - Works on desktop, tablet, and mobile devices
- ✅ **Professional Templates** - Three pre-designed signature styles

## 🚀 Usage

### Step 1: Open the Generator
Simply open `email-signature-generator.html` in your web browser.

### Step 2: Choose a Template
Click on one of the three template styles:
- **Modern** - Two-column layout with vertical divider
- **Classic** - Traditional single-column layout
- **Minimal** - Compact, clean design

### Step 3: Fill in Your Details
Enter your information in the form:
- Required: Name, Title, Company, Email
- Optional: Phone, Website, Address, Logo, Social Media

### Step 4: Customize Colors
Use the color pickers to set:
- **Primary Color** - Main accent color
- **Text Color** - Body text color
- **Accent Color** - Secondary highlights

### Step 5: Copy Your Signature
Choose one of two copy options:

**📋 Copy Signature** (Recommended)
- Copies the formatted signature
- Paste directly into email client settings
- Preserves all formatting and styling

**💻 Copy HTML**
- Copies the raw HTML code
- Useful for manual editing
- Required for some email clients

## 🎨 Customization

### Changing Default Colors
Edit the CSS variables in the `<style>` section:

```css
:root {
    --cyber-cyan: #00f3ff;      /* Primary cyan */
    --cyber-blue: #0ff;         /* Secondary blue */
    --cyber-dark: #0a0e27;      /* Dark background */
    --cyber-darker: #050814;    /* Darker background */
    --cyber-purple: #9d00ff;    /* Purple accent */
    --cyber-pink: #ff00ff;      /* Pink accent */
}
```

### Adding Custom Fonts
Replace the Google Fonts import with your preferred fonts:

```html
<link href="https://fonts.googleapis.com/css2?family=YourFont:wght@400;700&display=swap" rel="stylesheet">
```

### Modifying Templates
Each template is generated by a function:
- `generateModernSignature(data)`
- `generateClassicSignature(data)`
- `generateMinimalSignature(data)`

You can edit these functions to customize the layout and styling.

## 📧 Email Client Setup

### Gmail
1. Copy your signature using "📋 Copy Signature"
2. Go to Gmail Settings → General → Signature
3. Create new signature
4. Paste (Ctrl+V / Cmd+V)
5. Scroll down and click "Save Changes"

### Outlook (Web)
1. Copy your signature
2. Go to Settings → View all Outlook settings → Compose and reply
3. Under "Email signature", paste your signature
4. Click "Save"

### Outlook (Desktop)
1. Copy the HTML code using "💻 Copy HTML"
2. File → Options → Mail → Signatures
3. Click "New" to create a signature
4. Click the HTML button (</>) in the editor
5. Paste the HTML code
6. Click "OK"

### Apple Mail
1. Copy your signature
2. Mail → Preferences → Signatures
3. Click "+" to add new signature
4. Paste in the signature area
5. Close preferences (saves automatically)

### Thunderbird
1. Copy the HTML code
2. Edit → Account Settings → [Your Account]
3. Check "Use HTML"
4. Paste HTML in the signature box
5. Click "OK"

## 💡 Tips & Tricks

### Best Practices
1. **Keep it Simple** - Less information is often more professional
2. **Test in Multiple Clients** - Always check how it looks in different email apps
3. **Use Web-Safe Fonts** - Stick to Arial, Helvetica, Georgia for maximum compatibility
4. **Optimize Images** - Keep logo files small (< 50KB) for faster loading
5. **Include Only Essential Links** - Too many social media icons can look cluttered

### Troubleshooting
**Signature looks different in email client**
- Email clients have limited CSS support
- Use the Classic template for maximum compatibility
- Inline styles work best (already implemented)

**Colors don't match**
- Some email clients override colors
- Use web-safe colors when possible
- Test with actual emails, not just preview

**Logo not displaying**
- Ensure the URL is publicly accessible
- Use HTTPS URLs only
- Keep image size reasonable (max 150px width)
